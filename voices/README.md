# Пресеты голосов для своего TTS (Fun-CosyVoice3)

| Файлы | Голос |
|---|---|
| `gemini.wav` + `gemini.json` | Энергичный научный диктор — клон голоса из ролика Gemini (`in/proj001/gemini_generated_video_bcfd18b7.mp4`) |

Образец — голос, отделённый от музыки (Demucs): 9,8 с, моно, 24 кГц, громкость выровнена.
`prompt_text` — дословная расшифровка образца. Голос синтетический (сгенерирован Gemini),
не запись живого человека.

## Установка на сервер TTS

Скопировать оба файла в каталог `voices/` сервиса `tts` (он смонтирован в контейнер
и перечитывается на каждый запрос — перезапуск не нужен):

```bash
scp voices/gemini.wav voices/gemini.json server:/data/apps/tts/voices/
curl -s -H "Authorization: Bearer $KEY" https://tts.cloudsmasters.ru/v1/voices   # должен появиться gemini
```

После этого голос сам появится на сайте Reels Studio в списке «Свой TTS».

## Как получить лучший результат

- `instruct` в пресете пустой — так сервер идёт через zero-shot клонирование (по образцу
  и расшифровке), это даёт максимальное сходство. Если на сайте выбрать «Подачу», сервер
  переключится на instruct-режим — сходство с образцом станет слабее.
- Образец говорит быстро и почти без пауз, и модель копирует эту манеру. Пишите текст
  короткими предложениями с «!», «?» или точкой на конце и отправляйте по одному
  предложению на запрос, склеивая с паузой 0,3–0,4 с (так делает `tools/clone_voice.py`).
- Числа — словами: нормализатор текста для русского выключен.
